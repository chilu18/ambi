# Demo script — target 75–85 seconds

Use fictional information only. Record live mode once API verification passes; label any sample-mode recording explicitly.

0–10s: “This is ambi. It helps independent workers turn an overwhelming moment into one small next step.” Show the opening workspace.
10–25s: Enter: “I was rejected for a job I wanted. Help me draft a short email asking for feedback.” Show the response and proposed step.
25–40s: “A suggestion is not my decision. I can edit it, and only then agree.” Edit the brief and click Agree & prepare draft.
40–55s: Navigate away while the server prepares the draft, then return. “ambi remembers the decision and keeps this bounded task moving.”
55–70s: Show the draft, placeholders and review checks. Copy it and mark it reviewed. “Nothing gets sent for me.”
70–85s: “Codex helped us build and test the full flow, including preventing a late background result from overwriting a reset workspace. Today it’s one useful draft. That’s the complete loop.”
